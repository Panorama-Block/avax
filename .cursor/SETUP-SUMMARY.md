## 🚨 Troubleshooting Rápido

### Context7 Não Funciona
```bash
# Reinstalar
npm install -g @upstash/context7-mcp@latest

# Verificar
npx @upstash/context7-mcp@latest --version

# Reiniciar Cursor
```

### MCP Não Aparece
1. Verificar `mcp-config.json` sintaxe
2. Reiniciar Cursor completamente
3. Verificar logs de erro nas dev tools

### Sugestões Ruins
1. Seja mais específico nos prompts
2. Use `use context7` para código complexo
3. Inclua contexto do projeto nas perguntas
